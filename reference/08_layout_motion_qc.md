# 08 · 布局测量、动效测量、审看循环

这一章是在一次 17 页、约 20 分钟的真实放映之后补进工作流的。当时只靠眼睛看了少数几步，用户仍指出「拥挤且重叠」；把每一页、每一步、四个 16:9 尺寸都量一遍，才找出 800 多个问题。下面的命令和门槛是那次用过、并且已经收进脚手架的。权威规范仍是 `00_spec`；这里写的是怎么执行，以及哪些错不要再犯。

脚手架运行时保持原样：整页离场、主题用 flood、`data-ref` 不计入页码。测量脚本对任何用这套运行时做的稿子都能跑。手递手衔接、共享元素飞行是打磨动效时要达到的标准，不是脚手架默认就已经做成的效果。

## 布局 QC（0 flag 才过）

设计空间是 1920×1080，舞台按视口等比缩放并留黑边。真正的 16:9（1920×1080、1600×900、1280×720、2560×1440）布局相同，四个尺寸是在证明缩放没有把字裁掉。检查器把坐标除以舞台缩放，阈值都写在设计像素上。

```bash
npm run qa:layout          # 现场：每一页 × 每一步 × 四个尺寸
npm run qa:layout:static   # ?mode=static，PDF 的终态
npm run qa:layout:mid      # 页内步骤动画停在 35% 和 70%，只记文字叠文字
npm run qa:type            # 1920 宽的字号普查
```

| 类型 | 门槛（设计 px） | 在查什么 |
|---|---|---|
| text-overlap | 墨迹盒相交超过 3×3 | 字压字 |
| text-on-media | 相交超过 4×4 | 字压在图、填充形或 SVG 色块上，且没有声明 |
| safe-area | 边距 5%（左右 96、上下 54），容差 6 | 墨迹出了安全区。页眉允许到 2% |
| tight-gap | 相邻文字块间距 < 24 | 挤 |
| small-type | < 18 | 比投影下限还小 |
| clipped / overflow-x | 行被 overflow 盒子切断（字罩 `.w` 容差 14，其余约 4px 或 0.2em，避开 em 盒的虚边） | 裁切 |
| image-outside-stage | 图的盒子出了舞台 | 图没有声明出血 |

笔画构成的 SVG 示意图不当事物图。全幅 SVG 视口不会把整页判成「字压在图上」。

故意的重叠写在标记上，不要把检查器关掉：

| 属性 | 含义 |
|---|---|
| `data-over` | 字故意压在照片或色块上。要另有衬底或字色保证能读；检查器不判断对比度 |
| `data-under` | 垫在字下面的底或色带 |
| `data-tight` | 一组标签 + 值，组内不要求 24px，组与组之间仍要 |
| `data-bleed` | 展示字可以贴边或出安全区 |
| `data-edge` | 照片或展示字故意出血 |
| `.head` / `data-furniture` | 页眉一类的固定件。可以更靠近边缘，仍检查字压字 |

每一处都要写进 `qa/layout-exceptions.md`：用在哪、为什么。目标是 0 条，或者每一条都有理由。

**0 条可能是空的。** 改完检查器或第一次接到新稿，故意叠两行字，确认它会被报出来（脚手架测试里有这一步）。只看总览图不够：这一次就是眼睛漏掉了 800 多条。

投影可读性（`qa-type`）：阅读文字在 1920 宽至少 22px（想再稳用 `--min 24`）；标签、出处、片尾可以到 18px，大写加字距或正常大小写，不能再小。挤的时候删句子或挪进讲稿，不要靠缩小字号。

页码：脚手架里 `data-ref` 不编号（现场写 “Not read aloud”，阅读版写 “References”），正文是 `01 / 05` 这种。参考文献如果会投出来，就去掉 `data-ref`，让每一页都进分母，并写一条测试钉死页脚。不要出现屏幕上有 17 页、页脚却写 `/16`。

`qa-shots` 里的盒子重叠是便宜的第二意见，墨迹检查才是门。两个都留着。

## 删掉的字要进讲稿

页面为了留白而缩短时，整句放进 `src/js/notes.js` 的 `moved`。演讲者窗口和 `speaker-notes.md` 会显示 “Moved off the slide”。主张、来源编号、署名不能悄悄消失：幻灯片上可以缩短，完整句子和 `[Rnn]` 留在 `moved` 或参考文献页。

口语字数只数 `cues`。把字挪走不会改变计时。

```bash
node scripts/qa-copy-moved.mjs previous-index.html index.html qa/copy-moved.md --notes src/js/notes.js --gate
```

`--gate`：某一页少了可见文字但 `moved` 是空的，或者 `[Rnn]` 从页面上消失又没有写进 `moved`，就失败。

## 动效 QA

两套，不要互相代替。

- `npm run qa:motion`：真实按 Next 的录屏，每按一次切一条 10 帧的胶片。给人眼看视线、跳、闪、残留。
- `npm run qa:run`：把每个 Web Animation 停住，按 60fps 的虚拟时间逐帧采样位置、尺寸和有效透明度。
- `npm run qa:handoff`：每个翻页边界上，旧字和新字是否同时达到 30% 可见并叠在一起。
- `npm run qa:frames -- <目录> S02.0` 和 `npm run qa:strip -- S02 0 out.png 0,150,300,500`：单次按键的胶片，给人眼看。

`qa-run` 的旗标：

| 旗标 | 含义 | 默认门 |
|---|---|---|
| snap | 一帧内位移/缩放超过 14px，且超过相邻帧的 3 倍加 4px | `--gate` 时必须为 0。`data-motion` 含 tense/stepped，或标了 `data-snap-ok`，阶梯缓动不记 snap |
| pop | 一帧内从不可见变成可见（透明度差 > 0.6），且没有动画在驱动它 | 必须为 0 |
| overlap | 旧页动画结束时刻减新页第一个非共享入场的 delay | 只报告。手递手稿用 `--overlap 150:250` |
| travel | 仅 `--reduced`：元素位置变化超过 4px | 减弱动效只能是淡入淡出 |

视频只从真实帧压：JPEG 序列会变成全范围的 `yuvj420p`，有的播放器会发灰。编码必须 `-vf scale=in_range=pc:out_range=tv,format=yuv420p -color_range tv`，再用 ffprobe 核对 h264、尺寸、60fps、`yuv420p`、tv，并做一次完整解码。帧目录在压完后删掉（一次全片可以到几百 MB）。`--no-video` 只出数字，用来快速看；交证据用带视频的全片。`--only` 会直接跳到要录的那一步并核对状态，只适合看一眼，不能代替全片。

采样必须看到 `currentTime` 真的往前走。曾经有一版检查器在 try/catch 里引用了页面拿不到的变量，时间根本没动，重叠数却是 0。

`deck.next()` 在动画进行中会先结束动画而不翻步。录制前要处于静止状态；若 Next 没有改变状态（例如视频的第一次确认），记 stuck 并跳到预期的下一步，避免后面的每一行都标错。分析时除了 `document.getAnimations()` 还要 `deck.finish()`，否则运行时自己记着的动画没结束，再按一次只是“结束动画”，步号全部错一位。

共享元素（项目自己实现飞行时）：两边都写 `data-shared="名字"`。检查器不会把共享飞行或页眉算进“新页第一个入场”，否则重叠会被算长（克隆体停在舞台上，不在某一页里）。页内飞行用 `data-flip-from="#选择器"`。找连续两页上都有的通栏色块、重复物体、大数字。

手递手（打磨时的标准，不是脚手架默认转场）：旧页按元素沿 `data-exit` 离开，新页第一个元素在旧页结束前约 200ms 开始，目标重叠 150–250ms（测试放宽到 120–280）。旧字在走完一半路程时已经淡掉，避免和落在同一位置的新字叠住。页眉是升上来换数字，不是硬切。减弱动效是一次 160ms 线性淡入，不位移。字罩从 `translateY(100% + .62em)` 起跳，否则 t=0 会露出字顶的一条。

脚手架现在的转场是整页离开（约 220ms），同主题时新页大约在 200ms 开始（测到的重叠约 20ms），换主题时新页更晚（会是一段空隙）。样稿上旧字和新字没有叠住，但还不是 200ms 的手递手。采用了按元素离场之后，再把 `--overlap 150:250` 和 `qa-handoff --gate` 放进这一轮的门。

## 给用户看的图

1. 艺术方向先做三张 styleframe（封面 + 最难的内容页），不要先做完全稿。用户选的写 `user_selected`，自己选的写 `self_selected`，两个词不要混用，也不要写成“用户已批准”。
2. `npm run qa:preview -- <N> --from <round> --note "..."` 写出 `qa/preview/batch-N/`。文件名带批次号，避免看图工具按路径缓存成上一版。
3. `npm run qa:endsheet` 把终态拼成总览。`npm run qa:compare -- <before> <after> <out>` 做前后并排，需要时加 `--crop W:H:X:Y`。
4. 用户改口的每一句写进 `design/decisions.md`，并引用原话。已经锁定的抄进 `handoff.md`，新会话不能悄悄改回去。
5. 口味上的选择给出两三个做法，选定一个并写明是 `self_selected`，其余留在批次目录里，一条命令可以换回去。

总览图上如果相邻两页对调构图也看不出来，其中一页就是模板。

## 设计质量（反馈里反复出现的）

- 不要每页都是「左上标题 + 眉题 + 细线 + 底部说明」。系统（角色色、网格、字号）可以共用，构图要变。家具用不同的摆法，而不是每页同一条顶线。
- 设计感应在版式和字号层级上，不要把所有字都设成等宽。等宽留给编号和引用 id。
- 不要橙 + 蓝这套现成配色。脚手架 `tokens.css` 里的橙和蓝是占位，P2 必须换掉。`qa-design` 会警告，直到强调色里不再同时有这两种色相。强调色不要拿来当字或细线，如果对比不够。
- 照片保持自然色、能看清。不要网点、半调、罩在照片上的点状 mask，也不要一层让照片发灰的半透明幕。字要压在照片上时，用局部衬底（`data-over`），不要给整张照片染色。
- 优先用有授权的真实照片，不要用 SVG 插画当素材。标记和图解可以写在 HTML 里，但要标 MADE HERE。占位照片要在画面上写明是占位，不是生成图。
- 动效是元素连续过去，不是整页硬切。缓动用离开型的曲线（快出慢收），不要 overshoot。线性只留给减弱动效和数字计数。可动的属性是 transform、opacity、clip-path；SVG 描边和计数是写明的例外。

`npm run qa:design` 会拦住半调 / 点状 mask。橙蓝、等宽标题、`assets/` 里的 SVG 只警告；`--strict` 时警告也失败。构图是不是重复，只能看总览图。

## 环境和发布顺序

- 用 `npm test`、`npm run qa:*`、`npm run release`。不要裸跑 `npx playwright`，否则可能装到和 `package.json` 里钉死的 `@playwright/test@1.63.0` 不同的版本。
- 下不了 Playwright 自带浏览器时：`PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/google-chrome`（或本机的 chrome.exe）。需要额外启动参数时用 `PLAYWRIGHT_CHROMIUM_ARGS`。
- 测试标题用单引号时，标题里的撇号会让文件解析失败，表现是 “No tests found”。改完跑 `npm test -- --list`。
- 全片 60fps 录制会跑很久。证据用全片；`--only` 和 `--no-video` 只用于查看。
- 发布顺序：`npm run qa:gate`（布局四尺寸、static、mid、字号、设计护栏）→ 需要时 `qa:run --gate` 和 `qa:handoff` → `npm test` → `npm run release`。`release` 自己会再跑一遍 `qa:gate`，然后才是讲稿、PDF、打包、冷启动。最后一次改动之后要重新打包，对一下产物时间戳，避免包是旧的。
- 打包调用 `bsdtar`（Windows 上是 `tar.exe`）。GNU tar 不能代替；没有 bsdtar 时 zip 这一步会失败。
- PDF 页面用 `pdftoppm` 打出来再看总览，不要只相信导出成功。

现场才能验证的（投影距离、翻页笔、教室电脑、有没有人听过声音）仍然写进 qa-report 的未测项，不把测量通过写成现场通过。
