# 03 · 设计系统与动效

## 两个“世界”和角色色
- 页面分成两个世界：**night**（沉浸：开场、媒体页、结论）和 **day**（审视：论证页）。哪一页属于哪个世界，本身是叙事的一部分。在 Nostalgia 里，night 是“在感受之中”，day 是“回头审视这种感受”。
- 颜色按角色命名：每个世界一组 `--night-*` / `--day-*`（bg、wash、text、meta、em、line、accent、accent-text、surface、glow），在 deck.css 里映射成 `--c-*`。组件只用 `--c-*`，不写 hex。
- 用户中途要求换配色，比如“参考 80 年代日本霓虹 + 梦核”，只需改 token，组件一行不动。多套色板并存时，用 `?palette=` 切换，并保留原方案。
- 对比度：小字放在强调色上时，固定用一对 ≥ 4.5:1 的颜色。Nostalgia 里粉底上的小字一律用 night 的墨色。
- 换世界只用 **flood**：新世界的背景从一条线长出来，铺满并超出四角，盖住旧世界。不要用 `transition: background`，深浅背景之间插值会经过发灰的中间色（QA 胶片条里看得到）。

## 字号与网格（1920×1080 逻辑画布的起点，以投影实测为准）
页边距 96；标题 80–140；正文 40–54；图表标签 28–36；来源 / 标签 22–28（等宽字体，大写，加字距）。整套最多两个字体家族；中文用系统 CJK 字体回退（`--cjk`）。正文太长时，先拆论证，或把展开内容放进讲稿，不要靠缩小字号塞进去。

## 页型（脚手架示例，每个项目重画）
开场媒体页 · 问题 / 主张页（两块在一条线上交汇）· 细读页（窗口里放图、按步出现标注、右侧三个问题）· 关系页（同一入口分成两条等价分支）· 结论页（开场的画面回来，被框起来）· 参考文献页。Nostalgia 另有：三段式时间带、唱片包装解剖、采样连线、不闭合的回返线。

## 反模板
不要默认用三列卡片、随处大圆角、玻璃面板、无意义渐变、图标墙、装饰性英文、反复出现的“巨字 + 小字”。确有信息结构上的理由才用，并写出理由。丰富感应该来自版式家族、主次关系和图像叙事，不要每页发明一个新特效。

## 设计质量护栏（审稿里反复犯过的）
这些在 P2 选方向时就查，不要等到全稿。`npm run qa:design` 能拦住其中几条，构图只能看总览图。细则和命令在 `08_layout_motion_qc.md`。

- **构图不要重复。** 把每一页的终态排成一张总览。相邻两页如果对调也看不出来，其中一页就是模板。系统（角色色、网格、字号）共用，构图要变。
- **设计感来自版式和字号，不是到处等宽。** 等宽留给编号和参考文献 id。
- **不要橙 + 蓝。** 这套配色读起来像模板。脚手架 token 里的橙色强调和蓝色强调是占位，选定方向时换掉。强调色对比不够时不要拿来当字或细线。
- **照片要能看清。** 自然色，不要网点、半调、点状 mask，也不要罩一层发灰的半透明。字要压在照片上时用局部衬底（`data-over`），不要给整张照片染色。
- **用有授权的实拍，不用 SVG 插画当素材。** 图解可以写在标记里，并标 MADE HERE。占位图在画面上写明是占位。
- **动效是元素接过去，不是硬切。** 见下一节。不要 overshoot，不要为了动而动。

## 动作语法（`motion.js`）
| 名称 | 层 | 用途 | 时长 / 缓动 |
|---|---|---|---|
| rise | L1 | 标题行从一条遮罩线里升起 | 420 ms，expo-out，依次错开 70 ms |
| fade | L1 | 标签、来源、块 | 260 ms，上浮 8 px |
| exit | L1 | 离开的页面加速离场 | 220 ms，ease-in |
| wipe | L2 | 条带、分隔线从左往右长出来 | 560 ms |
| draw | L2 | SVG 引线、分支 | 640 ms，用 stroke-dashoffset |
| slide-l / slide-r | L2 | 两个对象相向靠拢 | 560 ms |
| flood | L3 | 换世界 | 420 ms，过冲到四角之外 |
| meter | L2·数字感 | 电平条一格一格跳满 | `steps(宽/20)`，640 ms |
| type | L1·数字感 | 等宽标签像液晶屏一样逐字打出 | `steps(字数)`，160 ms + 14 ms/字，最长 640 ms |
| load | L2·数字感 | 窗口里的图片按横条从上往下加载（像慢速下载） | `steps(9)`，720 ms |

- **一条原则：** 模拟的东西平滑地动，数字的东西一格一格地动。阶梯式揭示只增加像素，不闪烁、不重复、不倒退。
- **预算：** 每页同一时刻只有一个主要运动焦点；入场编排 ≤ 700 ms。
- **禁止：** 循环、脉冲、旋转、弹跳、抖动、故障效果、闪白、粒子、镜头光晕、RGB 分离。
- **不用 setTimeout 串联：** 全部用 WAAPI，任何时候 `finishAll()` 都能直接落到最终状态。

## 动效策略（2026-10-15 的教训）
- **每次启动都是完整动效。** 不跟随系统的 `prefers-reduced-motion`（学校和远程桌面常把“显示动画”关掉），也不把选择存进 localStorage（`file://` 和 `http://` 是两个地址，各存各的，会导致“双击 index.html 和用服务器打开不一样”）。
- 需要减弱时：按 A（只对本次有效），或者打开 `?motion=reduced`。
- 减弱模式下所有动作变成 160 ms 的淡入，阶梯式动作全部关闭。`qa:run --reduced --gate` 会把仍在移动的元素标成 travel。

## 手递手（打磨动效时的标准）
脚手架的默认转场是整页离开再进下一页，同主题时重叠只有大约 20ms，换主题时新页还要等 flood。样稿上旧字和新字没有叠在一起，但这还不是连续的手递手。

打磨到这一步时：旧页按元素离开，新页第一个元素在旧页结束前约 200ms 开始（目标 150–250ms），旧字在路程过半时已经淡出。页眉升上来换页码，不要硬切。连续两页上的通栏、重复物体、大数字用共享元素飞过去（`data-shared`；页内则是 `data-flip-from`）。检查：`qa:run --overlap 150:250 --gate` 和 `qa:handoff --gate`。字罩的起点要低过遮罩的内边距，否则第一帧会露出一条字顶。

线性缓动只留给减弱动效和数字计数。脚手架里 `fadeIn` 目前仍是线性的，这是基线，不是打磨后的目标。

## 风格层（可选，Nostalgia 的 D15 / D17 是参考实现）
- 放在单独的 CSS（例如 `retro.css`）里，`?style=plain` 可以整层关掉。只在这一层出现的元素加 `.rx`，只在关掉时出现的加 `.plain-only`。
- 每个母题都要和论点挂钩。在 Nostalgia 里：
  - 侧边 obi 条、Side A / B、铬字标题，把演示包装成一张“再版唱片”，对应 S08 对再版包装的分析。
  - 千禧年风格的图片窗口标题栏显示真实文件名，表示“这张过去的图，是今天打开的一个文件”。
  - 唱片封面式的贴纸和电平条也属于这一层。
- 风格层可以带自己的动作（数字感的那几种），但仍然遵守上面的禁止清单。
- 静态模式要把这一层的固定装饰复制到每一页，否则导出的 PDF 里没有。
